# Практическая работа по CSS

Многостраничный учебный сайт с общей внешней таблицей стилей.

## Файлы проекта

- `index.html` — главная страница
- `index01.html` — расписание занятий; на этой второй странице добавлена иллюстрация
- `index02.html` — страница «CSS на практике»
- `style.css` — единое оформление всех страниц
- `assets/study.jpg` — изображение для страницы расписания

Откройте `index.html` в браузере или запустите локальный HTTP-сервер в этой папке.
